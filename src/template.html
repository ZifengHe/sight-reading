怎么用它练视奏

整页是一条连续的乐谱：从入门（中央C五指位置）开始，经过一级到十级，每级 58 首（共 638 首），难度一首一首往上加。每首练习单独占一屏（两行），弹的时候谱面不动，弹完自动翻到下一首。每次打开都会重新谱写一套从没见过的新谱（视奏要练的就是“第一次看到”）。“设置”里显示的“谱号”可以记下来：网址后面加 #谱号（例如 sight_reading.html#2024）就能找回同一套；点“换一套新谱”则重新谱写全部练习。

进入心流的方法

  • 选一个“刚好有点难”的级别：能弹对 80%–90% 就是最合适的难度。太轻松就往后跳，太吃力就退一级或把速度调慢。
  • 不要停。光标不会等你（除非开了等待模式）。弹错了就跳过去，跟上下一拍——这是视奏最重要的习惯。
  • 眼睛看在光标前面：光标在这一小节时，眼睛已经在读下一小节。整首都在同一屏上，谱面不会移动，视线可以放心往前走。
  • 每首开始前有预备拍（橙色倒数），这时谱面已经翻到新的一首，先看清调号、拍号和最难的地方。预备拍长度可在“设置”里改成 2–3 小节，多给自己一点看谱时间。
  • 打开“自动接下一首”后可以一直弹下去，难度会自然上升，不用停下来找谱。

常用设置

  • 速度：按每首推荐速度的百分比调整。↑↓ 每次 ±5%。
  • 声音：“全部播放”=先听一遍再弹；“只播我不弹的手”=分手练习时让电脑弹另一只手；“静音”=完全自己弹，只跟光标。
  • 循环本曲：同一首反复练（第二遍以后就不算视奏了，适合难点）。
  • 点击谱面任意小节即可从那里开始。

连接电子琴 / MIDI 键盘（Chrome、Edge）

  • 用 USB 连接后，点“⚙ 设置”里的“🎹 连接 MIDI 键盘”。连上后工具栏里会出现 🎹 状态（手机横屏在左侧按钮下方），按任意琴键会显示音名（例如 C4），说明琴已经接通。
  • 按 ▶ 播放，跟着光标弹：弹对的音符变绿，漏掉的变红；小窗里实时显示 ✓弹对 ✗漏掉 错=多弹的音。每首结束会弹出这首的正确率。不按播放时弹琴不会评分。
  • 等待模式：光标停在每个音上，弹对了才往前走，适合刚开始练某一级的时候。

iPhone / iPad（横屏）

  • 横屏使用：每首练习刚好一屏两行。上下滑按页翻动，左右滑换上一首/下一首，点小节从那里开始。
  • 添加到主屏幕（Safari → 分享 → 添加到主屏幕）：以后从桌面图标打开，全屏、没有地址栏，谱面更大。
  • 第一次要点“播放”才会出声（iOS 规定声音必须由手指触发）。iOS 16.4 以上静音开关打开也能出声；如果还是没声音，拨开静音开关、调高媒体音量。
  • 手机屏幕较矮，屏幕键盘默认关闭，可在“设置”里打开；高级别里特别密的曲子在手机上会自动变成 4–6 小节，保证音符看得清。
  • iPhone / iPad 上的 Safari、Chrome 等浏览器都不支持 MIDI。想在 iPhone / iPad 上用“弹对变绿”和等待模式，可以试试用 MIDIWeb Browser 这类支持 Web MIDI 的 App 打开本页网址；电脑上的 Chrome / Edge 可以直接用。

学曲子（📖 按钮）

  • 载入曲谱：点“📖 学曲子 → 📂 载入曲谱文件”，选 MusicXML（.musicxml / .xml / .mxl）或 MIDI（.mid）文件。MuseScore 等打谱软件都能导出 MusicXML。曲谱只存在这台设备上。
  • 学习计划（默认，推荐）：App 把曲子切成每段 4 小节（约一句），按顺序安排好每一步，你只管按 ▶ 弹。每段：没学过的手先单手练（等待模式 → 70% → 原速），另一只手由 App 弹、谱上画成浅色；再双手（等待模式 → 60% → 80% → 原速）；和前面学过的小节一样的手不再单独练。从第二段起每段和上一段连起来；每 4 段连成一大段；最后整首。每步连续弹对 2 遍（原速 3 遍）自动进入下一步。等待模式需要 MIDI 键盘：你弹对了光标才往前走；没连 MIDI 时这一步改成 50% 慢速。手动调慢速度或换手，那一遍不计。练法里还可以选“上一步”“跳过这步”“从第 1 步重来”。
  • 选范围（自由循环、速度阶梯、从后往前时）：输入起止小节，或点“👆 在谱上点选范围”后在谱上点两下。范围会循环播放，每遍之间有一小节预备拍。
  • 速度阶梯：从较慢的速度开始（例如 60%），连续弹对几遍（默认 3 遍）就自动加快 5%，一直到原速。
  • 从后往前：先练范围的最后一两小节，过关后自动往前加一段，越往后越熟，每次都完整弹到结尾。
  • 判断“弹对”：连上 MIDI 键盘时自动判断（60 个音以内：没有漏音、错音不超过 1 个；更长的段落每 60 个音允许错 1 个）；没有 MIDI 时，自己觉得弹对了就点“✓ 这遍弹对了”。
  • 易错小节：每遍的对错按小节累计，越常错的小节底色越红，下次先练那几小节。“我弹”选右手或左手就是分手练习，另一只手由电脑弹。
  • 每首曲子一个链接：打开一首曲子后点“🔗 这首曲子的链接”，把链接发给自己（微信、iMessage 都行），在 iPhone 上用 MIDIWeb Browser 打开就直接进入这首曲子，不用再传文件。曲库里的歌链接很短；自己的曲谱交给 Claude 加密上传后也是短链接（密钥只在链接里），否则整份压缩在链接里，链接较长。只发给自己。
  • 有反复记号的曲子（包括 D.C.、D.S.、Fine、Coda）会按演奏顺序展开，小节号按展开后的顺序编。
